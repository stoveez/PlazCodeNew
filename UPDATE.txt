PlazCode 1.18.59

Changes:
- Fix startup after updating from an older hidden/background PlazCode instance. A new build now reuses only an already-running instance with the exact same desktop version; older background versions are replaced so the new window can open normally.
- Add regression coverage for same-version reopen versus older-version replacement.
- Correct the desktop redesign so the implemented app closely follows the approved PlazCode previews instead of only borrowing their colors.
- Add custom-painted orange glow layers, navy depth, preview-style navigation selection, a branded PlazCode mark, and the large Welcome to PlazCode hero treatment.
- Increase the dashboard proportions and card hierarchy to match the approved layout more closely while keeping the decorative mountain/landscape artwork out.
- Rebuild Tools into the preview-style three-column live catalog with RS / AS / PC / MCP filters, source badges, availability states, and no decorative per-tool images.
- Rebuild MCP Servers into a three-column live server catalog with status glow, descriptions, commands, tool counts, and enable/disable controls, without decorative server artwork.
- Replace the plain utility-style desktop layout with the production PlazCode dashboard design: stronger sidebar, branded header, cleaner status cards, quick actions, recent activity, and improved spacing.
- Redesign Tools as a real data-driven RS / AS / PC / MCP catalog with source filters and searchable live entries; no decorative marketplace images or fake tool metadata.
- Redesign MCP Servers as a live server-management catalog with primary Roblox Studio status plus real optional-server states and enable/disable actions; no decorative server artwork.
- Redesign Terminal and Settings around the same dark navy + orange glow language while keeping all existing bridge, autosave, background, permissions, reasoning, and MCP behavior.
- Add a branded PlazCode runtime icon and stamp the same PlazCode identity into the packaged Windows executable so File Explorer, taskbar, and titlebar no longer use the generic app icon.
- Rename the obvious Windows desktop launcher to PlazCode.exe. plazcode-agent.exe is still included as a compatibility alias.
- Redesign the native desktop control center around the extension's dark navy + warm gold PlazCode theme.
- Closing the desktop window now hides it while the bridge keeps running in the background. Launching PlazCode.exe again reopens the existing background instance instead of starting a second bridge.
- Add an explicit Exit PlazCode action for actually shutting the background process down.
- Desktop settings autosave immediately to plazcode-settings.json and restore after hiding, exiting, reopening, or rebooting.
- Existing saved desktop settings are authoritative after reopen. The browser extension only seeds the desktop settings file on the first run when no saved desktop settings exist yet.
- Keep desktop and extension settings synchronized through the authenticated loopback bridge.
- Make the desktop Tools page source-aware and complete: Roblox Studio tools, AgentScript workspace tools, optional MCP add-ons, and browser-side PlazCode utility/skill/motion tools are merged into one searchable catalog.
- Keep the MCP server catalog with optional Blender, Context7, Fetch, Git, Memory, and Sequential Thinking entries. Roblox Studio remains the protected primary server.
- Reduce long-chat CPU/DOM churn by throttling diagnostic DOM mirroring, lowering idle camouflage sweep frequency, and replacing the always-on high-frequency bar layout loop with adaptive scheduling.
- Fix staged-media memory retention by revoking blob URLs when media is removed, cleared, or the page unloads.
- Preserve every provider adapter and the existing background/provider message contract. Notion remains the known live-site exception from the previous baseline.

Regression validation:
- JavaScript syntax checks run for background.js, popup.js, core/*.js and providers/*.js.
- Provider adapters remain hash-protected; the intentional core/main.js performance update has its own updated baseline hash.
- Existing parser, ChatGPT, Claude, skills, animation, v1.11, v1.12, v1.15, and v1.18 regression tests run in GitHub Actions.
- Desktop regression checks validate the settings relay, browser-tool relay, performance guards, and version.
- Rust cargo check and cargo test run on Windows.
- Rust tests include settings persistence across process reopen and normalization of invalid saved choices.
- The Windows workflow builds PlazCode.exe, embeds the branded Windows icon, and packages PlazCode-1.18.59.zip.
- Live authenticated provider smoke tests are still required before merging the draft branch because GitHub Actions cannot drive the user's logged-in AI website sessions.

Install / test:
1. Close the old PlazCode process completely before replacing files.
2. Keep your old plazcode-agent.exe as a rollback copy if desired.
3. Extract PlazCode-1.18.59.zip and replace the previous PlazCode folder.
4. Reload the unpacked extension in chrome://extensions.
5. Refresh every already-open supported AI chat tab. Reloading the extension alone leaves the old content scripts running.
6. Run PlazCode.exe.
7. Change several desktop settings, close the window, reopen PlazCode.exe, and verify the settings remain unchanged.
8. Open Tools and verify RS, AS, PC, and MCP source labels appear as those tool sources become available.
9. Test the currently working AI websites in a normal chat and a long existing chat. Notion remains the known exception for this release.

Background behavior:
- X / Hide: hides the desktop UI but leaves the PlazCode bridge running.
- Launch PlazCode.exe again: reopens the already-running desktop instance.
- Settings > Exit PlazCode: fully exits the process.

Security boundary:
- Local command and desktop endpoints still require the pairing key.
- Optional MCP servers remain disabled until explicitly enabled.
- Roblox Studio MCP cannot be removed from the catalog.
- The pairing key stays outside the release ZIP.
- No new Chrome permissions were added.

Distribution:
- Distribute the complete PlazCode-1.18.59.zip.
- Keep the extension and desktop app from the same build together.
