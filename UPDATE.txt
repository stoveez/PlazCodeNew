PlazCode 1.18.54

Changes:
- Turn the native PlazCode agent window into a desktop control center with Home, Tools, MCP Servers, Console and Settings pages.
- Keep the existing browser extension and every provider adapter as the AI-facing layer. The desktop app does not replace or rewrite provider DOM integrations.
- Synchronize desktop settings with the extension through the existing authenticated 127.0.0.1 bridge. Existing extension settings are preserved on the first desktop sync.
- Mirror Roblox/AgentScript engine, Fast/Balanced/Thorough work mode, Sandbox/Ask/Full permissions, reasoning level, Extra Thinking, Plan Mode, Forge UI, Auto Fix, Background Mode and Sounds in the desktop app.
- Add a live desktop tool browser and MCP server catalog.
- Add optional MCP catalog entries for Blender, Context7, Fetch, Git, Memory and Sequential Thinking. Roblox Studio remains the protected primary MCP server.
- Add authenticated custom MCP add/remove support to the native bridge. Add-on tool names are isolated with a server prefix so they cannot collide with Roblox Studio tools.
- Keep the existing extension/background message contract intact. Every existing provider/core JS file is hash-protected by the desktop regression suite.
- Restore the source layout under core/, providers/, agent/ and ui/ and remove the accidental flattened source duplicates.
- Both extension and rebuilt agent report 1.18.54.

Regression validation:
- JavaScript syntax check runs for background.js, popup.js and every core/provider JavaScript file.
- Provider/core integrity guard verifies the existing browser provider code was not changed by the desktop work.
- Existing parser, ChatGPT, Claude, skills, animation and version regression suites run in GitHub Actions.
- Rust cargo check and cargo test run on Windows.
- The shipping workflow builds the Windows release agent and creates PlazCode-1.18.54-SHARE.zip.
- Notion remains the known live-site exception from the 1.18.53 baseline. Its provider adapter is preserved and hash-protected; this release does not claim Notion is fixed.
- Live browser smoke testing is still required before promoting the draft build to final because GitHub Actions cannot drive authenticated AI websites in your Chrome profile.

Install:
1. Close the old PlazCode agent.
2. Keep plazcode-agent.old.exe as your rollback copy.
3. Extract PlazCode-1.18.54-SHARE.zip and replace the previous PlazCode folder.
4. Reload the unpacked extension in chrome://extensions.
5. Refresh every already-open supported AI chat tab. Reloading the extension alone leaves old content scripts running.
6. Start the new plazcode-agent.exe. The PlazCode desktop control center opens and automatic extension pairing continues to use the existing local pairing flow.
7. If you enable an optional MCP server, make sure its launcher command (for example npx or uvx) is installed on the PC.

Security boundary:
- Command requests still require the local pairing key.
- Desktop settings and MCP catalog endpoints use the same authenticated loopback API as the existing extension bridge.
- The pairing endpoint keeps the existing extension-ID/content-type/origin validation.
- Optional MCP servers are disabled until the user explicitly enables them.
- The Roblox Studio MCP entry remains protected and cannot be removed through the catalog.
- The key stays outside the release directory and is never included in the ZIP.
- No additional Chrome permissions were added for the desktop app.

Distribution:
- Distribute the complete PlazCode-1.18.54-SHARE.zip produced by the release workflow.
- Do not distribute only changed files: the extension and agent versions must stay matched.
